# Full-Stack IVR Delivery Confirmation

A small dashboard that lets a telecaller trigger an automated IVR call to confirm a delivery. The
customer confirms with a keypress (or by saying Yes/No), and the result is saved against the delivery.

Full setup, provider rationale, architecture and assumptions are documented below as the project is
built out.
